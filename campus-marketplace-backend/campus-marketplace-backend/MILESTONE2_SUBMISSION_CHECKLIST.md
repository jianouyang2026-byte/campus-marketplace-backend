# Milestone 2 Submission Checklist

## Required Deliverables

- GitHub repository link with backend code and documentation
- 6-10 minute video demonstration
- API list with expected input and output
- Sample JSON input and output for each API
- Database design and tables
- Test case document and API test results
- Working backend API code integrated with a database

## Files Included

| File | Purpose |
|---|---|
| `server.py` | Working REST API backend |
| `app_postgres.py` | Flask REST API backend connected to PostgreSQL |
| `schema_postgresql.sql` | PostgreSQL database table design |
| `init_postgres_db.py` | Creates PostgreSQL database tables and seed data |
| `requirements.txt` | Flask, PostgreSQL, and pytest dependencies |
| `.env.example` | Example PostgreSQL connection settings |
| `schema.sql` | Database table design |
| `test_api.py` | Automated API tests |
| `demo_api_operations.py` | Video demo script showing API responses and database evidence |
| `API_DOCUMENTATION.md` | API list with sample JSON input and output |
| `DATABASE_DESIGN.md` | Database tables and relationships |
| `TEST_CASES_RESULTS.md` | Test cases and test result summary |
| `README.md` | Run and test instructions |
